<objective>
Relocate the MemPalace store onto the per-owner shared Claude volume so a developer's memory palace travels across all of their workspaces, in every template whose startup_script initializes MemPalace.

Purpose: Today each workspace inits a fresh ~/.mempalace on its own home volume, so memory captured in one workspace is invisible in another for the same owner. The per-owner shared volume already mounted at $HOME/.claude-shared is the correct home for portable, owner-scoped state (same pattern proven for ~/.claude and ~/.claude.json).

Output: Six modified template main.tf files, each with an idempotent migrate-and-symlink block inserted before the `mempalace init` guard, and the guard's absence-test rewritten to an empty-palace test.

<assumption_delta_decision>
The migration block PROMOTES the shared volume ($HOME/.claude-shared/mempalace) to the primary palace location and DEMOTES the per-workspace ~/.mempalace directory to a one-time migration source (then a symlink). This is a required→shared / per-workspace→per-owner identity-model shift, adopted deliberately to match the existing dot-claude promotion in the same startup_script. Advisory, non-blocking.
</assumption_delta_decision>
</objective>
