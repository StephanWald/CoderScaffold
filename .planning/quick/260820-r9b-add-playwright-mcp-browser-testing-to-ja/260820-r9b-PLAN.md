browser-testing loop: a Playwright MCP server it can call, backed by a real
chromium binary baked into the image.

Add a dedicated, self-documenting layer to each of the three Dockerfiles that

the Playwright MCP (registered in Task 2) can launch a headless browser.

COMMAND (use in each Dockerfile):
```
# ── Playwright chromium + OS deps ────────────────────────────────────────────
# Bakes the chromium browser AND its shared libs (libnss3, libatk, ...) so the
# Playwright MCP server (registered in the agent startup_script) can drive a
# headless browser for self-serve UI testing. Done at build time so workspace
# boot has zero per-start cost. --with-deps pulls the apt libraries; the browser
# binary lands under a system path (PLAYWRIGHT_BROWSERS_PATH default), so it
# survives the volume-shadowed /home mount at runtime.
RUN npx -y playwright@latest install --with-deps chromium
```

<task type="auto">
  <name>Task 2: Register the Playwright MCP server in the three startup_scripts</name>
  <files>templates/java-fullstack/main.tf, templates/python-ai/main.tf, templates/bbj-services/main.tf</files>
  <action>
In each template's `coder_agent` `startup_script`, add a Playwright MCP
registration block IMMEDIATELY AFTER the existing "webforJ MCP server" node-merge
block, mirroring it exactly (same guard, same idempotency, same WR-03
warn-and-continue). The shared config file is `$CLAUDE_SHARED/dot-claude.json`.

BLOCK TO ADD (adapt the WARN text; keep structure identical to the webforJ block):
```
    # ── Playwright MCP server — preconfigure in user-scope Claude config ───────
    # Registers the Playwright MCP server (npx @playwright/mcp) under the
    # top-level "mcpServers" key of the shared ~/.claude.json, so Claude Code can
    # drive the chromium browser baked into the image for self-serve UI testing.
    # Merged with node (guaranteed present in the image) so existing config/auth
    # are preserved. Idempotent: re-asserts the entry on every start. Non-fatal
    # under set -e (WR-03 warn-and-continue): a missing node or a write failure
    # must NEVER abort the startup_script — log and continue.
    if command -v node >/dev/null 2>&1; then
      CLAUDE_JSON="$CLAUDE_SHARED/dot-claude.json" node -e '
        const fs = require("fs");
        const f = process.env.CLAUDE_JSON;
        let cfg = {};
        try { cfg = JSON.parse(fs.readFileSync(f, "utf8") || "{}") || {}; } catch (e) {}
        cfg.mcpServers = cfg.mcpServers || {};
        cfg.mcpServers.playwright = { command: "npx", args: ["-y", "@playwright/mcp@latest"] };
        fs.writeFileSync(f, JSON.stringify(cfg, null, 2) + "\n");
      ' || echo "WARN: could not register Playwright MCP server; continuing" >&2
    else
      echo "WARN: node not found; skipping Playwright MCP registration" >&2
    fi
```
