<objective>
Bake two tmux quality-of-life defaults into all six workspace images by writing a
system-wide `/etc/tmux.conf`:

- `set -g mouse on` — wheel-scroll into scrollback, click-to-select pane/window,
  drag-to-resize in the Coder browser web terminal (which otherwise cannot reach
  tmux's scrollback, since tmux owns the alternate screen).
- `set -g history-limit 50000` — raise per-pane scrollback from tmux's 2000-line
  default so long build/test output stays reviewable.

Source-side only, matching the tmux auto-attach setup from quick-260823-8wn.
Takes effect on image REBUILD only — expected, same as the auto-attach change.
</objective>

already installed in all six images by that task; this only adds the config file.
