# Phase quick-260823-qz4 Plan 01: tmux Mouse Mode + Larger Scrollback

**One-liner:** Baked a system-wide `/etc/tmux.conf` (`set -g mouse on` + `set -g history-limit 50000`) into all six workspace images so the durable web-terminal tmux session gets mouse scroll/select/resize and 50k-line scrollback.

## What Was Built

Commit: `d704825`

In all six workspace Dockerfiles, added a `RUN printf '%s\n' ... > /etc/tmux.conf && chmod 0644 /etc/tmux.conf` layer immediately after the existing `/etc/bash.bashrc` auto-attach block, writing:

```
set -g mouse on
set -g history-limit 50000
```

Each is preceded by a dense comment (matching the surrounding style) explaining that `/etc/tmux.conf` is tmux's global config, read before user config, and lives on the image so it survives the volume-shadowed `/home/coder` at runtime — the same reasoning as the auto-attach snippet from quick-260823-8wn.

- `mouse on` — wheel-scroll into scrollback, click-to-select pane/window, drag-to-resize in the Coder browser web terminal (which otherwise can't reach tmux's scrollback, since tmux owns the alternate screen).
- `history-limit 50000` — per-pane scrollback up from tmux's 2000-line default so long build/test output stays reviewable.

**bbj-services:** written in the `base` stage (line 231, between `FROM ... AS base` @44 and `FROM base AS bbjinstall` @238); `final` is `FROM base AS final` @281 and inherits it.
