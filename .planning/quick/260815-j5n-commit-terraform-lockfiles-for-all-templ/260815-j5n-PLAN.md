<canonical_commands>
Per template directory (use an ABSOLUTE path for the -v source):

  docker run --rm --user "$(id -u):$(id -g)" \
    -v "<abs-template-dir>:/tf" -w /tf hashicorp/terraform:1.9 \
    init -backend=false -input=false

  docker run --rm --user "$(id -u):$(id -g)" \
    -v "<abs-template-dir>:/tf" -w /tf hashicorp/terraform:1.9 \
    providers lock -platform=linux_amd64 -platform=linux_arm64 -platform=darwin_arm64

Platform rationale: prod provisioner is linux/amd64, local Docker engine is linux/arm64, dev Mac is
darwin_arm64. `--user` prevents root-owned files in the repo. TF_PLUGIN_CACHE is NOT needed.

FALLBACK: because `--user` gives the container a non-existent HOME, Terraform may complain it cannot
write a CLI config dir. If (and only if) that happens, add `-e HOME=/tmp` to the `docker run` args.
Do not add it pre-emptively.
</canonical_commands>
