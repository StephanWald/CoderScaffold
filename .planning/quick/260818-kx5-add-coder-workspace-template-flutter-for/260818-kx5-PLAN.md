# Quick Task 260818-kx5 — flutter/dart workspace template

A new Coder workspace template for **Flutter / Dart** development, mirroring the
existing `templates/python-ai` and `templates/java-fullstack` skeleton (same Claude
Code + MCP + GSD + MemPalace + docker-outside-of-docker + git-over-SSH plumbing),
with the Python/Java toolchain layer replaced by the Flutter SDK (which bundles Dart).

## Requirements (from user)

1. A template for Flutter / Dart development.
2. Claude Code "as usual" and git "as with all our other templates" — i.e. the same
   shared plumbing every other template ships.

## Decisions (inferred from the existing templates)

- **Mirror `templates/python-ai`** file-for-file for the shared skeleton, swapping the
  toolchain layer. Keep: per-owner shared Claude volume + symlink migration,
  `bypassPermissions`, webforJ MCP, MemPalace MCP + `mempalace init`, GSD (gsd-core),
  optional `git_repo` clone, docker-outside-of-docker socket mount + `group_add`,
  git-over-SSH forge known_hosts + `accept-new`, `gh` CLI, persistent home volume,
  Node.js LTS, `127.0.0.1 → host.docker.internal` init_script rewrite.
- **Drop JupyterLab** (Python-specific).
- **Toolchain**: Flutter SDK cloned to `/opt/flutter` (system-wide, outside the
  `/home/coder` volume that shadows baked-in home paths), `flutter`/`dart` symlinked
  into `/usr/local/bin`. Dart ships inside the SDK. `flutter precache` is run at build
  so the Dart SDK + artifacts bake into the image (no per-boot download).
- **Build-time channel parameter** `flutter_channel` — `stable` (default) or `beta`,
  passed as the `FLUTTER_CHANNEL` build arg; part of the image name + triggers so
  switching rebuilds/caches a distinct image. `mutable = true`.
- **IDEs**: code-server (browser VS Code, with the Dart + Flutter extensions
  pre-installed), VS Code Desktop (SSH), JetBrains Gateway → IntelliJ IDEA Ultimate
  (`IU`, supports the Dart/Flutter plugins) — same trio as java-fullstack.
- **Icon** `/icon/flutter.svg` (Coder built-in). `[LIVE-VERIFY]` at push time.

## Implementation

New `templates/flutter/` (auto-discovered by `scripts/push-templates.sh`):

- **`main.tf`** — copy of `python-ai/main.tf` with:
  - `python_version` param → `flutter_channel` param (stable/beta, icon flutter.svg)
  - image `build_args`/name/triggers use `FLUTTER_CHANNEL` instead of `PYTHON_VERSION`
  - agent `env` exports `FLUTTER_HOME=/opt/flutter` + `PUB_CACHE`/PATH parity
    (replacing the `UV_*` vars)
  - JupyterLab module + fallback block removed
  - jetbrains-gateway `jetbrains_ides = ["IU"]`, `default = "IU"`
  - code-server gains `extensions = ["Dart-Code.dart-code","Dart-Code.flutter"]`
    ([LIVE-VERIFY] Open VSX ids)
  - header comment + `folder` handling unchanged
- **`Dockerfile`** — copy of `python-ai/Dockerfile` with the uv/CPython/AI-SDK/
  JupyterLab layers replaced by:
  - Flutter build deps (`curl git unzip xz-utils zip libglu1-mesa`)
  - `git clone -b ${FLUTTER_CHANNEL} https://github.com/flutter/flutter.git /opt/flutter`
  - `git config --system --add safe.directory /opt/flutter` + `chown coder:coder`
    (avoid git "dubious ownership" when the coder user runs the root-cloned SDK)
  - `flutter --disable-analytics` + `flutter precache` (bake Dart SDK + artifacts)
  - symlink `flutter`/`dart` → `/usr/local/bin`; `/etc/profile.d/10-flutter.sh`
    exports `FLUTTER_HOME` + PATH (incl. `~/.pub-cache/bin`)
  - keep Node LTS, git-SSH known_hosts, MemPalace CLI, `gh`, the DooD comment block
- **`README.md`** — mirror python-ai's README (what it provides, /opt rationale,
  private-repo SSH, push/configure, **deferred live-verification checklist**).
- **`.terraform.lock.hcl`** — copy java-fullstack's (identical provider set:
  coder 2.18.0 + kreuzwerker/docker 4.5.0 + hashicorp/http 3.6.0, same module comp).

## Verify

clones an optional repo, exposes VS Code (browser + desktop) + IntelliJ + Claude Code +
MCP + GSD + MemPalace, and is pushed by the existing bulk script.
