### Dockerfile (Task 1)

**git.basis.cloud keyscan (non-standard port 10022):** Added a separate `ssh-keyscan -p 10022` invocation inside the existing ssh-keyscan RUN, appending to `/etc/ssh/ssh_known_hosts` with the same warn-and-continue idiom as the standard-port loop. **`/usr/local/bin/components-checkout` helper:** Printf-baked (0755) in its own RUN immediately after the bbj helper scripts block. Script shape:
- `set -euo pipefail`
- `REPO` defaults to `ssh://git@git.basis.cloud:10022/BASIS/components.git` (overridable via `COMPONENTS_GIT_URL`)
- `DEST="${BBJ_SRC_DIR:-$HOME/bbj}/components"`
- If `$DEST/.git` exists: `git -C "$DEST" pull --ff-only` (idempotent update)
- Else: `git clone "$REPO" "$DEST"` (first run)
- No SVN credentials referenced anywhere

### main.tf (Task 2)

**`coder_script.components_checkout`:** Non-fatal WR-03 script placed immediately after `coder_script.bbj_checkout`. Attributes match `bbj_checkout` exactly: `run_on_start = true`, `start_blocks_login = false`. Script logic:
